# Danny Galvis Portfolio

Personal portfolio highlighting cybersecurity projects, work experience, research, leadership, and awards.

## Preview locally

Run `python -m http.server 8000` from this folder, then open http://localhost:8000.

The site uses plain HTML, CSS, and JavaScript in `index.html`. Photos and project evidence are stored in `assets/`, with source notes in `assets/SOURCES.md`. The downloadable resume is `dannygalvis-resume.pdf`.
